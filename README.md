# IntellMeet – AI-Powered Meeting & Collaboration Platform

IntellMeet is an AI-powered meeting and collaboration platform designed to make online meetings more productive and organized. It combines real-time communication, meeting intelligence, task management, and analytics in one application.

The platform helps teams collaborate effectively, capture important meeting information, identify actionable tasks, and track progress.

## 🚀 Live Demo

**Live Application:**  (intell-meet-zidio-eight.vercel.app/)

**GitHub Repository:** (https://github.com/Shikhar-Dewangan/IntellMeet-Zidio/)

## ✨ Key Features

- **Real-Time Video Meetings:** Connect and collaborate through online video meetings.
- **AI-Powered Transcription:** Capture meeting conversations as text.
- **Meeting Summaries:** Generate concise summaries to help users review important discussions.
- **Smart Action Items:** Identify important tasks and follow-up activities from meetings.
- **Team Chat:** Communicate and share information with team members.
- **Task Management:** Organize tasks and track project progress.
- **Analytics Dashboard:** View meeting-related information and productivity insights.
- **Full-Stack Architecture:** Integrates a React-based frontend with a Node.js and Express backend and MongoDB database.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have installed:

- Node.js and npm
- MongoDB or a MongoDB Atlas connection
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Shikhar-Dewangan/IntellMeet-Zidio.git
cd IntellMeet-Zidio
```

### 2. Set Up the Backend

```bash
cd backend
npm install
```

Configure the environment variables required by the backend in a `.env` file. Use the variable names expected by the application source code.

Start the backend using the development or start script defined in `backend/package.json`.

### 3. Set Up the Frontend

Open a separate terminal:

```bash
cd frontend
npm install
```

Configure the frontend environment variables, including the backend API URL, if required by the application.

Start the frontend using the script defined in `frontend/package.json`.

> **Note:** Exact start commands, environment variable names, and service configuration should be confirmed from the project's package files and source code.

## 🔐 Configuration and Security

- Store API keys, database credentials, and authentication secrets in environment variables.
- Do not commit `.env` files or other sensitive credentials to GitHub.
- Configure the frontend to communicate with the correct backend deployment URL.
- Restrict production database access and configure appropriate server security settings.
